BodgeBall
entre amigos.

Os arquivos abrem no seu computador. A sala conecta vocês pela internet, mesmo em casas diferentes.

Cada amigo deve abrir este mesmo pacote no próprio PC. Envie o código da sala — o endereço 127.0.0.1 não serve para convidar alguém de outra casa.

Como começar uma partida de 2v2 a 4v4
  1. Uma pessoa cria a sala. Dentro do jogo, pressione Tab para ver o código e as opções.
  2. Os outros jogadores digitam o mesmo código nesta tela.
  3. Em Tab → Create Custom Game, escolham os times, mapa e modo. Para 4v4, deixem quatro jogadores de cada lado.
  4. Os convidados clicam em Ready Up. O anfitrião clica em Start Match.
  5. Joguem no Chrome ou Edge, com a aba do jogo visível. O anfitrião deve ficar conectado durante a partida. Na primeira abertura, aguarde o carregamento dos cenários.

O carregador só atende este computador; não é necessário abrir portas para ele no roteador. A conexão WebRTC depende das redes dos jogadores e dos serviços de sinalização/relay incluídos no jogo. Se não conectar, tentem outro anfitrião e desliguem a VPN, se estiverem usando.
